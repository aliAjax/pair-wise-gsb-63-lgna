# 游乐设施日常检验与缺陷闭环平台

基于 Vue3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket 和 Vite 的独立前端工程。数据默认保存在 localStorage，无需后端即可演示。

## 功能

- 检验任务列表、关键词和状态/区域筛选、统计概览。
- 新建检验任务，逐项录入磨损、异响、制动、锁止和安全装置结果。
- **断网补录与回网合并**：
  - 补传批次冻结现场采集时刻与离线基线版本，回网时做字段级三路合并。
  - 仅离线改过取离线值，仅值班室改过保留在线值；**同一字段两边都改过则两个值并列保留**为待裁决冲突。
  - 回网合并后设备进入合并锁定，**值班长确认前不能恢复开放**（安全停用始终允许）。
  - **复测通过**并经值班长确认后才写入放行、关闭缺陷、恢复开放。
  - 放行按批写入，**某批失败只重试该批**，其他批次不受影响；**已确认批次不可重放**（幂等键=批次号）。
  - 值班室可在断网期间重开/停用设备、改派责任人、登记复测，作为三方对账的在线侧。
- 设备、检验记录、缺陷、放行记录、补传批次五类实体贯通。
- **旧数据首次打开自动迁移**：补齐设备/缺陷档案与检验记录基线（baselineVersion=1），保留原结论。
- 审计时间线与待办统计**只按当前有效版本**，被合并/裁决取代的历史条目可展开追溯但不计数。
- JSON 记录导出、版本号和完整操作时间线。

## 启动

```bash
npm install
npm run dev
```

访问 `http://localhost:18463`。

## 构建与规则校验

```bash
npm run build      # 类型检查 + 生产构建
npm run verify     # 三路合并/迁移 29 条 + store 端到端流程 25 条
```
